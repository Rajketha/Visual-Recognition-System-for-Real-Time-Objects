How It Works

5 simple steps to real-time object detection

Click Start
Activate Camera

Action: Click green "Start Camera" button

Result: Requests camera permission

Duration: 2-3 seconds

Live Feed
Mirror Preview

View: Real-time mirrored camera feed

Status: "Live View Active" message

Ready: Click Start again for detection

Click Again
Enable Detection

Action: Click Start button second time

Status: Changes to "Detecting..."

Overlay: Green glow appears

Bounding Boxes
Objects Detected

Visual: Green rectangles around objects

Labels: Object name + confidence %

Example: "CHAIR DETECTED (92%)"

Stop When Done
Clean Shutdown

Action: Click red "Stop Camera" button

Result: Camera + detection stops

Keyboard: ESC key also works
